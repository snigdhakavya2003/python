# 🐍 Python Practice Hub

An AI-powered Python quiz app. Select a topic, pick a difficulty level, get a fresh question generated by AI, submit your answer, and receive instant feedback.

---

## 🛠️ Tech Stack
- **Backend**: FastAPI + Groq API (LLaMA3)
- **Frontend**: Streamlit
- **AI**: Groq (free, 14,400 requests/day)

---

## ⚡ Quick Setup

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Set your Groq API key
```bash
# Copy the example env file
cp .env.example .env

# Edit .env and paste your Groq API key
# Get a free key from: https://console.groq.com
```

### 3. Run the Backend (Terminal 1)
```bash
cd backend
uvicorn main:app --reload
# Running at http://localhost:8000
```

### 4. Run the Frontend (Terminal 2)
```bash
cd frontend
streamlit run app.py
# Opens at http://localhost:8501
```

### 5. Open in browser
```
http://localhost:8501
```

## 🚀 Deploy (Free)

### Backend → Render.com
1. Push to GitHub
2. Connect repo to Render
3. Set `GROQ_API_KEY` in Render environment variables
4. Set start command: `uvicorn backend.main:app --host 0.0.0.0 --port 8000`

### Frontend → HuggingFace Spaces
1. Create a new Space (Streamlit type)
2. Push `frontend/app.py` to the Space repo
3. Set `API_URL` secret to your Render backend URL
